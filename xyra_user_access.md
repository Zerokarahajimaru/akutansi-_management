# Xyra.id - Data Akses Pengguna (Handover)

Dokumen ini berisi informasi kredensial login untuk sistem manajemen inventaris Xyra.id. Mohon simpan dokumen ini dengan aman dan **segera ganti password** setelah login pertama kali untuk alasan keamanan.

---

## 1. Halaman Login
Akses sistem dapat dilakukan melalui URL berikut:
- **URL:** [Sesuaikan dengan domain Render kamu]/login

---

## 2. Kredensial Akun (Default)

### 2.1 Tingkat: Administrator
Administrator memiliki akses penuh ke seluruh fitur sistem, termasuk manajemen data master dan pembuatan akun pegawai.

| Nama Pengguna | Username | Password | Role |
| :--- | :--- | :--- | :--- |
| Ezara Aristo | `admin` | `admin` | Admin |
| Super Admin | `superadmin` | `password` | Admin |

### 2.2 Tingkat: Pegawai
Pegawai memiliki akses untuk operasional harian seperti input penjualan, pembelian, dan cek stok. Pegawai tidak dapat menghapus data penting atau mengubah role akses.

| Nama Pengguna | Username | Password | Role |
| :--- | :--- | :--- | :--- |
| Siti Aminah | `siti` | `pegawai123` | Pegawai |
| Andi Wijaya | `andi` | `pegawai123` | Pegawai |
| Rina Pratama | `rina` | `pegawai123` | Pegawai |
| Fajar Hidayat | `fajar` | `pegawai123` | Pegawai |
| Dewi Lestari | `dewi` | `pegawai123` | Pegawai |

---

## 3. Instruksi Keamanan Penting

1.  **Ganti Password Segera:** Setelah berhasil masuk, klik ikon **Gear (Pengaturan)** di bagian bawah sidebar kiri untuk mengganti password ke yang lebih kuat.
2.  **Fungsi "Remember Me":** Gunakan fitur ini jika Anda ingin tetap login di perangkat yang sama tanpa harus mengetik ulang username setiap kali membuka browser.
3.  **Audit Trail:** Setiap transaksi yang disimpan akan mencatat siapa user yang sedang login. Pastikan setiap staf menggunakan akun mereka sendiri (jangan meminjamkan akun).
